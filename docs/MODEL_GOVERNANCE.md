# Model Governance

AI is replaceable reasoning infrastructure. Provider sessions and memory are nonauthoritative. AI may extract candidate state, summarize evidence, classify candidate intent, draft documentation, flag conflicts, reason over workflows, and prepare typed tool requests. It may not establish clinical truth, choose treatment, mutate authoritative objects, grant authority, bypass policy, execute healthcare actions, or fabricate missing facts.

Every capability has a registry entry: owner; intended users/population/setting/purpose; decision role; prohibited uses; provider/model/version; prompts/retrieval/configuration; data handling; evaluation set; validity/safety/fairness results; thresholds; monitoring; approval; rollback; kill switch; change history.

Outputs must be schema validated, source linked where material, uncertainty labeled, and evaluated before release. Provider abstraction must support deterministic local test models and substitution for Gemini or another provider without domain changes.
