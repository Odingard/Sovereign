# Architecture Decision Records

ADRs use: Status, Context, Decision, Consequences, Rejected Alternatives, Verification. Accepted ADRs are immutable; a change creates a superseding ADR. Material domain, authority, safety, data, workflow, provider, or stack decisions require review before implementation.
